# Web3 Token Vesting Basic

This project helps beginners learn how token vesting works in blockchain projects.

You will learn:
- What token vesting is
- How to connect a wallet
- How to check vested balance
- How to claim tokens
- How Web3 time-based contracts work

## Requirements
- Node.js installed
- MetaMask browser extension
- Basic JavaScript knowledge

## Setup

1. Clone the repo
git clone https://github.com/yourusername/web3-token-vesting-basic.git

2. Install packages
npm install

3. Run the app
npm start

4. Open browser
http://localhost:3000

## Project Structure

- index.html = Main webpage  
- app.js = Frontend logic  
- vesting.js = Vesting contract functions  
- web3.js = Blockchain connection  
- deploy.js = Contract deploy script  
- config.js = Network settings  
- server.js = Local server  
- package.json = Project info  
- utils.js = Helper functions  
- .env.example = Environment example  

## Features
- Connect wallet  
- Check vested amount  
- Claim tokens  
- Show vesting schedule  
- Simple vesting dashboard  

## Learning Goal
This project explains how tokens are released over time using blockchain.
